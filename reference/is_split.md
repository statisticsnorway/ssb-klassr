# Given a graph and a node, determine if the node is a split code.

Given a graph and a node, determine if the node is a split code.

## Usage

``` r
is_split(graph, node)
```

## Arguments

- graph:

  A graph generated by [`klass_graph`](klass_graph.md).

- node:

  A node as returned by [`klass_node`](klass_node.md) or
  [`V`](https://r.igraph.org/reference/V.html).

## Value

`TRUE` if the node is split, otherwise `FALSE`.

## Details

The function will attempt to reconcile nodes that have split and then
later merged again. A node is considered to be split if there is more
than one node that does not itself have children (i.e. nodes at the end
of a sequence of changes) that can be reached from `node`
