# Identify corresponding family from a classification number

Identify corresponding family from a classification number

## Usage

``` r
get_family(classification)

GetFamily(klass)
```

## Arguments

- classification:

  Classification number

- klass:

  Deprecated; use `classification` instead.

## Value

Family number

## Examples

``` r
get_family(classification = 7)
#> [1] "1"
```
