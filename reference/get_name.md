# Get the name of a classification version

Get the name of a classification version

## Usage

``` r
get_name(version)

GetName(version)
```

## Arguments

- version:

  Version number

## Value

string or vector of strings with name of version

## Examples

``` r
get_name("33")
#> [1] "Yrkesklassifisering 08 (STYRK-08) "
```
