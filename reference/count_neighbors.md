# Count the neighbors of a node.

Count the neighbors of a node.

## Usage

``` r
count_neighbors(graph, node, mode)
```

## Arguments

- graph:

  A graph generated by [`klass_graph`](klass_graph.md).

- node:

  A node as returned by [`klass_node`](klass_node.md) or
  [`V`](https://r.igraph.org/reference/V.html).

- mode:

  Whether to query outgoing (‘out’), incoming (‘in’) edges, or both
  types (‘all’). This is ignored for undirected graphs.

## Value

A numeric vector of length one giving the number of neighbors.
